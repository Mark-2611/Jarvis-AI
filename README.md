## 📖 About

An AI-powered desktop voice assistant built with Python.

Jarvis can understand voice commands, remember information, open applications, browse the web, and answer questions using Google's Gemini AI.

---
# ✨ Features

- 🎤 Wake Word Detection
- 🗣 Voice Recognition
- 🔊 Text-to-Speech
- 🧠 Gemini AI Integration
- 💾 Long-Term Memory
- 💬 Conversation Memory
- 🌐 Browser Automation
- 💻 Desktop Automation
- 🧰 Modular Tool Architecture
- ⚙ Environment Variable Support (.env)

# ⚙ Installation

Clone the repository

```bash
git clone https://github.com/YOUR_USERNAME/Jarvis-AI.git
```

Install dependencies

```bash
pip install -r requirements.txt
```

Create a `.env` file

```
GEMINI_API_KEY=YOUR_API_KEY
```

Run Jarvis

```bash
python src/main.py
```
